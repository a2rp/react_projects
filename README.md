# React Projects

A collection of complete React applications built to explore practical product workflows, interface patterns, and frontend engineering.

## Projects

- **[Northstar - CRM Sales Pipeline](projects/crm-sales-pipeline/README.md)** - A sales workspace for opportunities, accounts, contacts, forecasts, and follow-up tasks.
- **[Kinfield CRM Contact Board](projects/crm-contact-board/README.md)** - A local-first contact workspace with relationship stages, follow-ups, search, and CSV export.
- **[Coursebook - Course Progress Tracker](projects/course-progress-tracker/README.md)** - A browser-local course dashboard for tracking lessons and progress across learning paths.
- **[Core HTML Interactive Notes](projects/core-html/README.md)** - An interactive HTML learning workspace with semantic, accessibility, form, and browser demos.
- **[Pactline - Contract Lifecycle Management](projects/contract-lifecycle-management/README.md)** - A frontend contract workspace for agreement records, reviews, renewals, and playbooks.
- **[Morrow Editorial Studio](projects/content-management-system/README.md)** - A frontend editorial workspace for planning, drafting, reviewing, and scheduling content.
- **[Hirly - Applicant Tracking System](projects/applicant-tracking-system/README.md)** - A frontend hiring workspace for managing roles, candidate profiles, interviews, scorecards, and pipeline stages.
- **[Morrow - Appointment Booking](projects/appointment-booking/README.md)** - A responsive appointment request flow for browsing services, choosing a time, and reviewing a booking.
- **[Assignment Planner](projects/assignment-planner/README.md)** - A local-first coursework planner with deadline tracking, assignment workflows, dashboard summaries, and CSV/calendar exports.
- **[Atlas Supply - Wholesale Marketplace](projects/b2b-wholesale-marketplace/README.md)** - A frontend procurement workspace for comparing products and suppliers, reviewing quote requests, and tracking purchase orders.
- **[Chakra UI Showcase](projects/chakra-ui-showcase/README.md)** - A responsive React showcase for exploring Chakra UI components, themes, working interface patterns, and practical examples.
- **[Clinic Management System](projects/clinic-management-system/README.md)** - A frontend-only clinic workspace for managing appointments, patient records, and care-team shifts with fictional demo data.
- **[BMI Calculator](projects/bmi-calculator/README.md)** - A responsive BMI tool with unit conversion, English/Hindi UI, browser-local history, and CSV export.
- **[Blood Bank](projects/blood-bank/README.md)** - A local-first donor directory demo with searchable records, validated registration, and fictional sample data.
- **[Book Reading List](projects/book-reading-list/README.md)** - A browser-local reading tracker for book status, progress, notes, and dates.
- **[Bookmark Organizer](projects/bookmark-organizer/README.md)** - A browser-local bookmark library with collections, favorites, search, and JSON export.
- **[BlueSky Workspace Solutions](projects/bluesky-workspace/README.md)** - A responsive workspace-services concept site with services, projects, pricing, and contact pages.
- **[Wine Dataset Statistics](projects/calculate-mean-median-mode-from-array-of-objects/README.md)** - A React dashboard comparing mean, median, and mode for measurements in the UCI Wine dataset.
- **[Calendar Planner](projects/calendar-planner/README.md)** - A browser-local month calendar for scheduling and reviewing personal events.
- **[Calorie Counter](projects/calorie-counter/README.md)** - A local-first meal tracker for logging calories and comparing daily intake with a personal goal.
- **[Calorie Intake Estimator](projects/calorie-intake-estimator/README.md)** - A client-side educational estimate of resting energy, maintenance calories, and a goal-adjusted intake target.
- **[Community Poll Builder](projects/community-poll-builder/README.md)** - A local-first community polling demo with poll creation, voting, search, and results.
- **[Murmur - Customer Feedback Dashboard](projects/customer-feedback-dashboard/README.md)** - A local-first feedback inbox for reviewing responses, tracking sentiment, and managing follow-up.
- **[Sonder - Customer Feedback](projects/customer-feedback-platform/README.md)** - A frontend workspace for organizing customer feedback, follow-up, and product themes.
- **[Harbor Customer Success Platform](projects/customer-success-platform/README.md)** - A customer success workspace for account health, renewals, playbooks, follow-up, and insights.
- **[Relay Customer Support Desk](projects/customer-support-desk/README.md)** - A frontend support workspace for conversation queues, customer records, and team reports.
- **[Dash Lead CRM Lite](projects/dash-lead-crm-lite/README.md)** - A browser-based CRM for lead pipelines, tasks, and follow-ups.
- **[Wayfarer Destination Discovery Guide](projects/destination-discovery-guide/README.md)** - A curated travel guide with style filters and a private saved list.
- **[Vela Digital Banking Dashboard](projects/digital-banking-dashboard/README.md)** - A frontend-only banking workspace for sample accounts, transaction review, demo transfers, card controls, and savings goals.
- **[Bowl and Bark](projects/dog-food-website-frontend-design/README.md)** - A responsive dog food storefront concept with product discovery, service, review, FAQ, and detail pages.
- **[Drishti Foundation](projects/drishti-foundation/README.md)** - A static foundation website concept with education, community, events, publications, and opportunity pages.
- **[Ecommerce Product Manager](projects/ecommerce-fronend/README.md)** - A React catalog and product-entry frontend connected to an ecommerce API.
- **[Tandem Seller Studio](projects/ecommerce-seller-dashboard/README.md)** - A local-first seller dashboard for orders, products, inventory, and sales activity.
- **[Morrow & Made Storefront](projects/ecommerce-storefront/README.md)** - A local-only storefront demo with catalog, cart, checkout, and sample order confirmation.
- **[Shiftline Employee Shift Scheduler](projects/employee-shift-scheduler/README.md)** - A browser-local workforce planner for weekly shifts, coverage gaps, team filters, and workload targets.
- **[Engineering DSA Foundations](projects/engineering-dsa-foundations/README.md)** - An interactive reference to data structures, algorithms, complexity, and problem-solving patterns.
- **[Engineering JavaScript Internals](projects/engineering-javascript-internals/README.md)** - An interactive guide to JavaScript execution, async behavior, memory, objects, and language features.
- **[Basic React Router App](projects/basic-react-router-app/README.md)** - A multi-page React starter demonstrating lazy routes, accessible navigation, responsive layouts, and static legal pages.

- **[Ledgerly ERP Business Operations](projects/erp-business-operations/README.md)** - A connected frontend workspace for sales orders, inventory, procurement, and receivables.

- **[Gatherwell Event RSVP Manager](projects/event-rsvp-manager/README.md)** - An event planning workspace for event details, guest responses, capacity, check-in, and exports.

- **[Exam Atlas](projects/exam-countdown-planner/README.md)** - A study planner for upcoming exams with countdowns, priorities, coverage notes, and local persistence.

- **[Ledgerly Expense Tracker](projects/expense-tracker/README.md)** - A browser-local income, expense, and budget tracker with searchable transactions and monthly summaries.

- **[GitHub Profile Finder](projects/fetch-github-profile/README.md)** - A profile lookup app for public GitHub accounts, with responsive profile details and repository metrics.

- **[Milepost Fitness Progress Dashboard](projects/fitness-progress-dashboard/README.md)** - A local-first workout tracker with activity history, weekly goals, trends, and CSV export.

Projects live in their own folders under `projects/`. Each project includes its own setup notes and any project-specific requirements.
