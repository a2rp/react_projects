# Good Paws: Pet Care Scheduler

Good Paws keeps routine pet care in one schedule in your browser. Track feeding, walks, medicine, grooming, and vet appointments for each pet.

**Collection source:** https://github.com/a2rp/react_projects/tree/main/projects/pet-care-scheduler

## Included

- Create pet profiles with a name, kind, and short detail.
- Add a care reminder for a selected pet with date, time, and care type.
- Switch between all pets or one pet, and upcoming or completed reminders.
- Mark a care task complete or reopen it later.
- Remove a reminder through a confirmation dialog.

## How to use it

Add each pet in the side form. Add reminders below the schedule, choosing which pet they belong to. Mark a reminder done when care is provided; use the pet cards to narrow the list.

## Data and limits

Pet profiles and reminders are stored in localStorage in this browser. Data is not encrypted or synced to other devices. The app does not send push notifications and does not replace veterinary advice. If browser storage is unavailable or full, changes remain available only until the page is closed.

This is a browser-only utility. Clearing the browser’s site data removes its saved information.

## Run locally

~~~sh

npm run dev
~~~
